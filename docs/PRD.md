# PRD — Family English Coach (家庭英语学习系统)

## 1. 产品定位

面向家庭成员的英语辅助学习工具。系统通过 ECDICT 种子词库维护单词库，驱动后续练习、计划、统计与激励。

> **当前实现：单人模式** —— 单成员账户（member id=1），词库经 ECDICT 脚本/SQL 种子维护；多成员切换、家庭排行榜已移除（排行榜页改为「我的进步趋势」单人页）。加词入口（AI 文本解析 / 手动录入）已按业务决策收敛为只读，是有意决策而非缺陷。

## 2. 目标用户

家庭成员（非专业英语学习者），需要简单直观的操作界面。当前为单人账户（member id=1）。

## 3. 核心用户流程

```
ECDICT 种子词库（只读） → 开始练习 → 记录掌握状态 → 查看统计 / 每周结算激励
```

> 词库经 ECDICT 脚本/SQL 种子维护，加词入口（AI 文本解析 / 手动录入）已按业务决策收敛为只读。详见 `docs/词库导入-ECDICT.md`。

## 4. 功能模块

### 4.1 单词管理

| 功能 | 说明 |
|---|---|
| 词库维护 | 经 ECDICT 脚本/SQL 种子导入；加词入口（AI 文本解析 / 手动录入）已按业务决策收敛为只读 |
| 单词查询 | 跨 Unit 搜词（关键词 / 标签 / 掌握度），见前端 `SearchView` |
| 标签系统 | ⭐ 收藏、🔥 高频、📚 考试重点、❌ 不再练习、✅ 已记忆 |
| 掌握状态 | 未学习 → 学习中 → 熟悉 → 永久记忆 |
| 显示策略 | 已永久记忆单词减少出现；高频/重点单词增加权重 |

**单词状态机：**

```
unlearned → learning → familiar → permanent
                         ↓
                     (可回退到 learning)
```

**标签与状态的独立性说明：**
- 标签是用户主动标记（收藏、高频等），影响出题权重
- 掌握状态是系统根据练习结果自动计算
- 两者独立运作，共同影响单词出现频率

### 4.2 学习计划

| 功能 | 说明 |
|---|---|
| 每日目标 | 设定每天学习/复习的单词数量 |
| 单元目标 | 选择要学习的 Unit 范围 |
| 截止日期 | 设定完成日期，系统自动拆分每日任务 |
| 自动规划 | 综合剩余时间、剩余单词量、掌握情况生成每日任务 |
| 新词+复习混合 | 每日任务包含新词学习和旧词复习 |

### 4.3 记忆模式

共 11 种练习模式（与后端 `PracticeMode` 枚举、前端 `frontend-vue/src/constants/modes.ts` 对齐）：

| value | 模式 | 说明 |
|---|---|---|
| flashcard | 单词卡 🃏 | 英文正面/中文背面翻转 |
| choice | 英→中 选择 🔘 | 给英文，选中文释义 |
| cn2en_choice | 中→英 选择 🔘 | 给中文，选英文 |
| spelling | 中→英 拼写 ✏️ | 给中文，拼英文 |
| en2cn_write | 英→中 默写 📝 | 给英文，写中文 |
| dictation | 听写 🎧 | 播放发音（TTS），写英文 |
| matching | 连连看 🔗 | 英中配对 |
| timed_challenge | 限时挑战 ⏱️ | 限时内连续作答 |
| scramble | 打乱重排 🔀 | 字母乱序还原 |
| memory_flash | 记忆闪卡 🧠 | 短时记忆回顾 |
| flip_match | 翻牌寻配 🔍 | 翻牌匹配 |

> 后端 `PracticeMode` 另含 `dialogue`（AI 场景对话），归 AI 助手页（`AiView`）承担，不计入练习页 11 种模式。原 PRD 中的「图片联想 / 跟读评分」未实现：跟读仅上线 TTS 发音，无 STT 评分；图片联想未做。

### 4.4 数据统计

| 指标 | 说明 |
|---|---|
| 全局掌握率 | 所有单词的掌握状态分布 |
| Unit 掌握率 | 每个 Unit 的掌握状态分布 |
| 学习趋势 | 每日学习量、正确率曲线 |
| 连续学习天数 | streak 统计 |

**掌握状态颜色规范：**

| 状态 | 颜色 | Hex |
|---|---|---|
| unlearned | 灰色 | `#9CA3AF` |
| learning | 橙色 | `#F97316` |
| familiar | 蓝色 | `#3B82F6` |
| permanent | 绿色 | `#22C55E` |

### 4.5 激励与复习（已上线）

| 模块 | 说明 |
|---|---|
| 错题本（WrongWordBook） | 练习答错自动收录，前端 `WrongBookView` 查看与重练 |
| SRS 间隔重复 | `backend/app/srs.py` 调度错题滚动复习（新词 → 复习 → 错题冲刺三类计划） |
| 每周结算 | `WeeklySettlement`：四维评分（XP / 完成度 / 稳定性 / 难度）+ bonus 封顶 + freeze + 徽章；前端 `WeeklySettlementView` |
| 现金激励 | 周学习现金分档 + 里程碑奖金，累计进 `Member.cash_balance` 虚拟钱包（`CASH_ENABLED` 开启，线下兑现）；详见 `docs/Settlement.md` |

## 5. MVP 范围

最小闭环，验证核心价值链：

```
ECDICT 种子词库（只读） → 单词卡/拼写/选择题练习 → 掌握状态记录 → 基础统计
```

**MVP 不包含：** 学习计划自动规划、AI 场景对话、听写、语音、Redis 缓存。

## 6. 非功能需求

- AI 调用必须通过抽象层，支持模型热替换
- 所有接口遵循 RESTful 规范，统一响应格式
- 数据库变更通过 Migration 管理
- 前端操作流程不超过 3 步完成核心任务

## 7. 术语表

| 术语 | 含义 |
|---|---|
| Unit | 一个学习单元，包含一组关联的单词 |
| Word | 一个学习条目，含英文、中文、所属 Unit |
| Tag | 用户标记，影响出题权重 |
| Mastery | 掌握状态，系统根据练习自动计算 |
| Practice | 一次练习行为（单词卡翻转、拼写、选择等） |
